Finalmente, organicé la ventana de la consola junto a las instrucciones del laboratorio para poder consultar los pasos y ejecutarlos de forma simultánea, reduciendo el riesgo de omitir instrucciones o realizar configuraciones incorrectas.

## Tarea 1: Acceder a una instancia de cuaderno en Amazon SageMaker

![Acceso AWS](Imagenes/Tarea%201.1.png)

![Acceso AWS](Imagenes/Tarea%201.2.png)

En la Tarea 1, accedí al servicio Amazon SageMaker desde la Consola de administración de AWS y, en el menú Applications and IDEs, seleccioné la opción Notebooks para localizar la instancia de cuaderno llamada MyNotebook; a continuación, utilicé la opción Open JupyterLab para abrir el entorno de trabajo asociado a la instancia. Este procedimiento se realizó con el objetivo de ingresar a JupyterLab, donde se encuentran las herramientas y cuadernos necesarios para desarrollar las actividades prácticas y ejecutar el código correspondiente al laboratorio.
